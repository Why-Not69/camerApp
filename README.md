# camerApp


Android-приложение для беспроводного управления Sony a6600 (и похожими камерами Sony со «Упр. со смартфона») по Wi‑Fi: живая картинка, ISO, выдержка,
кнопка «Фото» или «Запись», таймер и зеркальное превью.

## 1. Сборка и установка на телефон

1. Установите **Android Studio**: https://developer.android.com/studio
2. Распакуйте архив. В Android Studio откройте **File → Open** и выберите папку `A6600Remote`.
   Первая синхронизация Gradle скачает нужные компоненты, это займёт 5–15 минут.
   Если Studio предложит обновить Android Gradle Plugin, можно согласиться.
3. На Xiaomi включите режим разработчика:
   - **Настройки → О телефоне** → 7 раз нажмите на **версию ОС**;
   - **Настройки → Расширенные настройки → Для разработчиков** → включите
     **Отладка по USB** и **Установка через USB** (Xiaomi может попросить войти в Mi-аккаунт).
4. Подключите телефон кабелем и разрешите отладку на экране телефона.
5. В Android Studio выберите свой телефон вверху и нажмите зелёный ▶ **Run**.

## 2. Настройка камеры

1. На камере: **MENU → Сеть → Упр. со смартфона (Ctrl w/ Smartphone) → Вкл.**
2. Там же откройте пункт подключения. На экране камеры появится ожидание подключения.
   Нажмите кнопку **с корзиной**, чтобы увидеть **имя сети (DIRECT-xxxx)** и **пароль**.
3. **Закройте Imaging Edge Mobile**: камера держит только одного клиента.

## 3. Первый запуск

1. На камере откройте **Упр. со смартфона → Подключение**, камера покажет QR-код.
2. В приложении нажмите **Сканировать QR-код камеры** и наведите телефон на экран камеры.
   Имя сети и пароль приложение возьмёт из кода. Android один раз спросит разрешение
   на подключение к сети камеры, подтвердите.
   Сканер встроен в Google Play Services, отдельное разрешение на камеру ему не нужно.
3. Другие варианты:
   - **«Уже подключён к камере в настройках Wi‑Fi»**: если телефон уже подключён к сети
     DIRECT-… через настройки Android, приложение просто использует это подключение;
   - **«Ввести вручную»**: имя сети и пароль с экрана камеры (кнопка с корзиной).
4. Дальше приложение подключается само при каждом запуске, а при обрыве связи
   переподключается автоматически.

Прочитать сохранённый пароль Wi‑Fi из настроек телефона приложение не может:
Android не даёт сторонним приложениям доступ к паролям.

## Управление

| Элемент | Что делает |
|---|---|
| Большая кнопка | Фото (белая) / старт записи (красная) / стоп (квадрат) |
| Таймер | выкл → 3 → 5 → 10 с. Повторное нажатие на кнопку во время отсчёта отменяет снимок |
| Режим | Фото ↔ Видео (если камера разрешает переключение по Wi‑Fi) |
| ISO · Выдержка · F · EV | Нажмите на значение, появится колесо (как в DJI). Крутите пальцем, значение применяется, когда колесо остановится. Тап по картинке закрывает колесо |
| Миниатюра последнего кадра | Открывает альбом |
| Альбом | Просмотр карты памяти камеры, сохранение снимков на телефон |
| Зеркало | Отражает превью, как в селфи-камере |
| ⚙ | Wi‑Fi, «Плавное превью», журнал и диагностика |

В горизонтальном положении телефона кнопка спуска переезжает вправо, параметры — вниз слева.

## Альбом

- **С телефона** («Альбом»): камера переключается в режим просмотра карты, превью на это
  время останавливается. «Назад» возвращает камеру в съёмку.
  Если камера не даёт открыть карту по Wi‑Fi, показываются снимки, сделанные из приложения.
- **На самой камере** (кнопка просмотра): приложение показывает подсказку и ждёт;
  когда вернётесь в съёмку, превью продолжится само.

## Если что-то не работает

Откройте **Лог → Копировать** и пришлите текст. Особенно важна строка
«Команды камеры», по ней видно, что a6600 разрешает делать по Wi‑Fi.

## Как устроено

- `camera/CameraWifi.kt`: подключение к Wi‑Fi камеры и привязка приложения к этой сети
  (иначе Android отправляет запросы через мобильный интернет).
- `camera/CameraDiscovery.kt`: поиск камеры (SSDP, затем стандартный адрес 192.168.122.1).
- `camera/SonyCameraApi.kt`: команды камеры (старый протокол Sony Camera Remote API, JSON-RPC).
- `camera/LiveviewParser.kt`, `LiveviewStream.kt`: разбор потока превью в кадры JPEG.
- `CameraViewModel.kt`: логика, переподключение, таймер.
- `ui/CameraScreen.kt`: интерфейс (Jetpack Compose).

## История версий

- **0.13** — проверка гипотезы про экономию энергии Wi‑Fi телефона: приложение каждые 20 мс шлёт камере крошечный пакет, чтобы радио не засыпало (переключатель «Не давать Wi‑Fi засыпать» в «Отладке»).
- **0.12** — в «Отладке» кнопка «Записать состояние камеры»: пишет в журнал всё, что камера сообщает о себе, и показывает, что изменилось с прошлого снимка.
- **0.11** — код превью и связи возвращён к версии 0.8.1 (диагностика 0.9–0.10 убрана); плавность превью, FPS и журнал перенесены в свёрнутый раздел «Отладка» в настройках.
- **0.10** — опрос состояния камеры настраивается (выкл / редко / постоянно, по умолчанию редко — раз в 4 с), в диагностике видно, сколько запросов состояния ушло и что в них менялось; часы камеры всегда в миллисекундах.
- **0.9** — диагностическая: номера кадров камеры (сколько снято / получено), время ожидания кадра и декодирования, сигнал и частота Wi‑Fi, чтение и декодирование в разных потоках, переключатель «свой сокет / стандартный», запись диагностики 30 с.
- **0.8.1** — часы камеры считаются в мс (убрана дёрготня из-за коэффициента 1.11), фокус в точке касания (если камера поддерживает setTouchAFPosition), список возможностей камеры в журнале.
- **0.8** — показ кадров по меткам времени камеры, снимок через полунажатие с проверкой фокуса, тап-фокус, название camerApp и новая иконка.
- **0.7** — поток превью через собственный сокет с TCP_QUICKACK, размер кадра в счётчике.
- **0.6** — интерфейс в стиле камеры Xiaomi, панель баланса белого (Авто / K / пресеты), буфер плавности.
- **0.5** — баланс белого, ползунок зума, сетка третей, исправлен поворот экрана.
- **0.4** — GPU-масштабирование превью, long poll событий, зум T/W, новый интерфейс.
- **0.3** — плавное превью, колёса настроек, альбом.
- **0.2** — подключение по QR-коду камеры.
- **0.1** — первая версия: превью, ISO, выдержка, фото/видео, таймер.
